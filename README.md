# Pahe Downloader

A web app to download all episodes of an anime from animepahe.si.

## Installation

1. Install dependencies: `pip install -r requirements.txt` (or use pyproject.toml)
2. Run the app: `python main.py`
3. Open http://127.0.0.1:5000/ in your browser.
4. Paste the anime URL and click download.

Note: This is for personal use only. Downloading copyrighted content may violate laws.
